# Excel_sales_Dashboard_Project
# Executive Summary 
& Profitability Dashboard (Microsoft Excel)An interactive Microsoft Excel business intelligence dashboard designed to transform raw European sales data into clear, actionable insights on revenue, profitability, regional performance, and sales channel distribution.Dashboard PreviewNote:
Make sure your uploaded screenshot filename matches Sales_Dashboard.jpg (or update the filename above).
Project ObjectiveThe goal of this project is to provide executives and stakeholders with a single-page, dynamic reporting view to:Monitor top-line revenue, cost of goods sold (COGS), and overall profitability.
# Track monthly sales and gross profit trends across the year.Identify top-performing European countries and regions.Compare revenue contribution across different sales channels.Filter performance dynamically by product category, country, and quarter.Key Performance Indicators (KPIs)The dashboard highlights six core business metrics at the top for quick executive review:
